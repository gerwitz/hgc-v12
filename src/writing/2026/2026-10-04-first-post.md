If I have set up everything correctly, this post will be visible in my Gemini capsule, but not my web site. It was created using Micropub (via IndieKit) but instead of using a traditional indieweb type like 'article' or 'note', it is a 'gempost'.

I found it necessary to make Gemini-only posts possible  because I want to send replies to others via my gemlog, without adding them to my web feeds. It needed to be a new type because gemlog convention requires even short notes have a title.
