Still more replace-Letta work this week, and have been able to "Hello World" ACP sessions. I don't know why I would expect otherwise, but it was really gratifying to see the local tools still work.

The big shift here is away from Letta's MemFS architecture. After a lot of consultation between myself and my synthetic colleagues, we settled on a bear's memory being persisted in a SQLite database. (We'll use Qdrant for embeddings, but treat them as ephemeral.) My initial motivation was the bulkhead to prevent leakage, but now I'm leaning into the way this will make bears portable.

Also tackled some overdue housekeeping on the Rust codebase, as it's growing so much larger than originally intended. We now have many crates and some better module hierarchy, though I'm not at all happy as a human reader, yet.
